# electrathon
Monorepo for CHS Electrathon car and pit crew station.
## Project Structure
There are three primary projects within this repository. They are:

- `frontend`: Svelte + Vite dashboard for user-facing voltage/amperage statistics
- `backend`: Basic FastAPI project that bridges the gap between the microcontroller and the front end
- `pico`: MicroPython code for the car and pit crew RPi Pico systems

Further details can be found in each project’s respective README.
