# Electrathon - `pico`
MicroPython code running on the car and pit RPi Pico W microcontrollers

## Development
### Dependencies
`uv` is used for package management. Running `uv sync` should be sufficient for installing dependencies into your virtual environment. From there, code will be copied onto the Pi.
### Running
Here is my workflow:
1. Make changes in VSCode
2. Copy files from VSCode to Thonny
3. Run code from within Thonny

Thonny will not be used for writing code in this workflow. It should only be used for running code written in VSCode.
