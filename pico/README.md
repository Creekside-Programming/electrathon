# Electrathon - `pico`
Contains all the code running on the RPi Pico in the car.

## Building
*Note: this software is only tested on Linux*
### Dependencies
All dependencies are installed as git submodules under `thirdparty/`, although `pico-sdk` requires special package installation that can be found [here](https://github.com/raspberrypi/pico-sdk?tab=readme-ov-file#unix-command-line).
